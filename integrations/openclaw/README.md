# 微信 ClawBot 接入


本项目通过 **OpenClaw 技能 → 已鉴权的后端命令 API** 接收微信操作，通过 **OpenClaw `/hooks/agent` → 已登录微信渠道** 推送消息。不会替代或重新登录已有微信机器人。若你的 ClawBot 并非基于 OpenClaw，仍可用命令 API 对接，但须适配该机器人的消息收发接口。

## 1. 后端配置

先在 Web 页面配置可用的百度网盘账号。更新依赖、重启服务。将模板中的 `media`、`clawbot` 配置合并到现有 `config/config.json`，不要覆盖已有账号和任务：

```json
{
  "media": {
    "base_url": "https://www.seedhub.cc",
    "cleanup_enabled": true,
    "settings": {
      "save_dir": "/追剧",
      "cron": "0 */6 * * *",
      "max_results": 5,
      "max_links": 18
    }
  },
  "clawbot": {
    "enabled": true,
    "api_token": "替换为随机生成的后端命令令牌",
    "gateway_url": "http://127.0.0.1:18789",
    "hook_token": "替换为OpenClaw的hooks.token",
    "agent_id": "main",
    "channel": "替换为已安装微信插件的实际channel标识",
    "account_id": "",
    "to": "替换为该微信渠道认可的接收人ID"
  }
}
```

用 `python -c 'import secrets; print(secrets.token_urlsafe(32))'` 生成令牌。`api_token` 和 `hook_token` 必须使用不同值，不能使用 Gateway 登录令牌代替 hook token。`account_id` 可留空以使用渠道默认账号。

`channel`、`to` 由你实际安装的微信渠道插件定义，不能假设所有插件都叫 `wechat`。先验证机器人自身能够给目标微信发送消息。Docker 内的 `127.0.0.1` 指向容器；跨容器请填写能访问 Gateway 的内部服务地址。跨机器连接使用 HTTPS 或可信私网，不要直接将未加固的服务暴露在公网。

## 2. OpenClaw 配置

在现有 OpenClaw 配置中合并：

```json
{
  "hooks": {
    "enabled": true,
    "token": "与后端hook_token相同",
    "path": "/hooks",
    "allowedAgentIds": ["main"],
    "allowRequestSessionKey": false
  }
}
```

把本目录的 `baidu-autosave` 文件夹复制到该机器人的 **workspace/skills/** 目录。在运行技能脚本的 OpenClaw 进程/容器中配置以下环境变量并重启，使技能及环境变量生效：

```bash
export BAIDU_AUTOSAVE_URL=http://127.0.0.1:5000
export BAIDU_AUTOSAVE_TOKEN='与后端api_token相同'
```

技能脚本只需 Python 3，无需安装本项目依赖。若 OpenClaw 使用执行沙箱，须允许沙箱访问本项目的后端地址，并将这两个环境变量注入实际执行脚本的沙箱。按微信插件自身提供的 allowlist/配对配置，仅允许服务所有者使用该技能，禁用不受信任群聊。此令牌提供全局任务和参数管理能力，不能分发给普通群成员。

验证配置并重启 Gateway 后，在微信发送“查看追剧参数”，再发送“搜索 影片名”。技能会将自然语言转换为命令。也可在 OpenClaw 所在环境直接试运行：

```bash
python3 /技能绝对路径/baidu-autosave/scripts/command.py '参数'
python3 /技能绝对路径/baidu-autosave/scripts/command.py '搜索 影片名'
```

## 3. 命令与接口

| 微信命令 | 行为 |
| --- | --- |
| `搜索 影片名` | 返回匹配影片的标题、年份/类型、评分及 ID，不扫描分享或创建任务 |
| `追剧 ID [更新频率]` / `获取影片 ID [更新频率]` | 使用搜索结果中的数字 ID，仅提取该影片的百度分享并创建定时转存任务；支持 `每周六周日6-8点`、`每天6-8点每30分钟` 或 `cron 0 6-8 * * 6,0`，尝试立即执行首次转存 |
| `任务` | 只返回任务名称和唯一 `task_uid` |
| `删除任务 ID` | 按 `task_uid` 删除指定追剧任务；例如 `删除任务 任务ID` |
| `参数` | 查看新任务默认参数 |
| `设置 save_dir /追剧` | 修改新任务默认保存根目录 |
| `设置 cron 0 */6 * * *` | 修改新任务默认转存计划，不影响已存在任务 |
| `设置 max_results 5` | 搜索最多返回的匹配影片数（1–20） |
| `设置 max_links 18` | 最多检查的百度入口数（1–18，旧配置超过 18 自动截到 18） |
| `检查更新` | 立即执行分享健康和一周无更新检查，不强制转存 |

后端命令接口：`POST /api/clawbot/message`，请求头 `Authorization: Bearer <api_token>`，JSON `{"text":"搜索 影片名"}`。未启用返回 403，令牌错误返回 401，命令错误返回 400，外部服务故障返回 502。不要把令牌放在 URL、截图或聊天回复里。

Web 登录后可使用 `POST /api/media/search`（JSON `{"name":"影片名"}`，返回 `results` 与匹配项目的 ID）、`POST /api/media/subscribe`（JSON `{"id":"118943"}`，不再接受影片名）及 `GET/POST /api/media/settings`。目前不新增前端页面。

首次转存由后台线程执行；任务创建成功不代表转存完成。执行器正忙时可能跳过即时执行，后续仍按 cron 运行。转存成功/失败沿用现有缓冲汇总通知，同时通过 Gateway 发给配置的微信接收人。删除任务也会推送原因。Gateway 接受事件不等于微信已经送达；发送失败不回滚转存或删除，也没有持久化重试队列。

## 4. 比较及自动清理规则

- 影片嗅探及每次转存均按同名作品识别 `S01`、`S01E12`、`Season 2`、`第十二季` 等目录/文件名，仅在同一分享明确存在多个季数时排除较低季，保留最高季全部集数及各版本，不是只保留最后一集。单季旧剧、不带季数的电影和无法确定归属的文件不按年份排除；不同作品独立判断。合集范围或不明确命名保守保留，不做模糊标题合并。
- 每个链接的嗅探结果会说明保留/排除的季数，最终回复及任务 `media.season_rule` 包含实际生成的路径排除正则（匹配则保留）。此规则独立于用户正则，不覆盖重命名规则；下次扫描自动重新生成，出现新季时切换，不删除已经保存的旧文件。

- 递归读取所有子目录，目录按 100 条分页；读取失败不能作为完整结果参与比较。仅视频文件参与影片候选排名，忽略字幕和海报。
- 每个分享先取**集数最高**的文件；最高集相同的多个文件取修改时间最新、再取文件最大的一个，作为该分享的最新一集。电影未识别集数时记为 0。
- 分享之间严格按**集数最大 → 该集修改时间最早 → 该集文件大小最大**择优。百度返回的修改时间不是 SeedHub 页面发布时间；缺失日期排在已知日期之后。
- 追剧采用串行低频流程：从 SeedHub 取到一个百度入口后，立即解析并读取该分享，再继续处理下一个入口；不会先集中解析所有百度链接后再同时请求百度网盘。SeedHub 当前没有可用的批量解析接口，因此首次检查仍会按资源数量产生请求。
- 追剧每次最多检查 18 个入口，每两个链接的最终结果合并发送（用换行分隔，最后不足两个也会发送），最后回复任务总结；最多 9 条结果加 1 条总结，不发送开场连接提示及单独的选择进度。链接包含已知提取码 `?pwd=...`，转存通知同样附带提取码；`max_links` 可在 1–18 内调低。
- 不填写更新频率时，以最终选中资源的最新文件更新时间为基准，在前后两小时窗口内每天每 30 分钟检测一次；显式填写频率时按用户指定规则执行。
- SeedHub 统一使用 `test.py` 中的 `curl_cffi` 请求方案（`safari17_0` 指纹及 iPhone Safari 请求头），不安装或启动浏览器。安装依赖或重建镜像后，可本地运行 `python seedhub.py search 地球超新鲜` 测试；旧配置中的 `request_mode` 会被忽略，已有 `media.base_url` 保留。403 不重试并记录 Cloudflare Ray ID；重定向自动跟随，临时网络错误最多尝试三次。
- 支持 `S01E12`、`EP12`、`E12`、`第12集`、`第十二集`、`12.mp4` 等常见命名。命名不规范时可能无法准确识别，应检查返回文件名及排名。
- 默认每小时检查**所有现有转存任务**，不仅是影片任务。明确返回分享失效/禁止分享码 115、145 或明确取消/过期信息时删除任务。
- 首次成功扫描建立基线，给予完整七天观察期；以后通过文件路径、大小、内容摘要及修改时间的指纹变化重置计时。连续七天内容不变，且没有七天内的文件修改时间时删除。重启保留观察状态。空分享也建立基线并适用此规则。
- 网络超时、登录过期、验证码、错误提取码、部分目录读取失败均保留任务；只有成功完整扫描才能据此判定超时。没有配置百度账号时不清理。执行中的任务暂不检查。
- 删除的是任务及其调度，**不会删除网盘中已经转存的文件**。可设置 `media.cleanup_enabled=false` 暂停清理。
- SeedHub 页面改版或反爬可能导致无结果。可在后端修改 `media.base_url`，但只应使用信任的站点；搜索范围受 `max_results` 和 `max_links` 限制，不承诺全站穷尽。
